Validity

Scenario: A detective presents two arguments. Argument A: "The butler was at the scene. Therefore, the butler was present." This is trivial — the conclusion merely restates the premise. Argument B: "If the butler was present, he heard the gunshot. The butler was present. Therefore, he heard the gunshot." This has genuine inferential power — the conclusion goes beyond the premises. Only one of these arguments is valid. Which one — and why?

The definition

DEFINITION [IFL2 Ch2]

Deductive validity

An inference is deductively valid iff no possible situation exists in which all the premises are true and the conclusion is false.

Equivalently: it is impossible for the premises to be true and the conclusion false simultaneously.

⚠ CRITICAL DISTINCTION

Validity ≠ truth of premises

Validity says nothing about whether the premises are actually true. A valid argument can have entirely false premises — and even a false conclusion — and still be valid. Validity is about the inference relationship, not premise truth.

Valid arguments with false premises

EXAMPLE

All birds can fly. Penguins are birds. Therefore, penguins can fly.

This is valid — the form guarantees the conclusion if the premises are true. It is unsound because premise 1 is false. Validity is preserved; only soundness fails.

Invalid arguments with true premises

EXAMPLE

Socrates is mortal. Plato is mortal. Therefore, all philosophers are mortal.

Both premises are true. The conclusion is also true. Yet the inference is invalid — two instances of a property do not logically entail universal quantification.

A counterexample: Descartes is mortal. is true, Spinoza is mortal. is true, but All philosophers are mortal is false — imagine a philosopher who is immortal. The form fails: you cannot infer "all Fs are G" from "some Fs are G".

Validity is about form

Every valid argument is an instance of a logically valid form — a schema that, when consistently reinterpreted, always yields truth-preserving inferences.

KEY INSIGHT [IFL2 Ch2]

The invalidity proof technique

To show an argument is invalid, produce a counterexample: a possible situation where all premises are true and the conclusion is false. The counterexample must preserve the argument's logical form while flipping the truth values appropriately.
