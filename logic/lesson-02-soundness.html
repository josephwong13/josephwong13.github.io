Soundness

Scenario: Two mathematicians each present valid proofs. Mathematician A's premises are empirically verified facts. Mathematician B's premises are unproven conjectures. Both proofs are structurally flawless. Only one gives you reason to believe the conclusion. What does B's proof lack?

Soundness defined

DEFINITION [IFL2 Ch3]

Soundness

An argument is sound iff it is both:

1. Valid — the form guarantees truth-preservation.
2. All premises are actually true.

If either condition fails, the argument is unsound.

⚠ WHY SOUNDNESS MATTERS

Valid ≠ Credible

A valid argument with false premises gives you no reason to believe its conclusion. The conclusion might be true — but the argument hasn't established it. Soundness is what turns logical validity into genuine epistemic warrant.

Valid vs sound — four combinations

WORKED EXAMPLE

Case 1 — Valid + true premises + true conclusion:

All humans are mortal. Socrates is human. Therefore, Socrates is mortal.
Both premises true. Form valid. → Sound argument.

Case 2 — Valid + false premises:

All birds can fly. Penguins are birds. Therefore, penguins can fly.
Premise 1 false. Form valid. Conclusion false. → Valid but unsound.

Case 3 — Invalid + true premises + true conclusion:

Socrates is mortal. Plato is mortal. Therefore, all philosophers are mortal.
Premises and conclusion all true. Form invalid. → Unsound (for invalidity).

Case 4 — Invalid + false premises:

All fish are mammals. Whales are fish. Therefore, whales are mammals.
Premise 1 false. Premise 2 false. Conclusion true. Form invalid. → Unsound on both counts.
