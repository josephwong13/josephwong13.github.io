Lesson 3 — Server Actions & Data Mutation

L3 Next.js Series · Lesson 3 of 5

Server Actions let you run server-side code directly from React Components — no API routes, no fetch calls. Forms become first-class reactive citizens.

What Is a Server Action?

An async function that runs on the server. You call it from a Client Component as if it were a local function — but it has direct DB access and runs on the server.

// app/actions.ts
'use server'

import { db } from '@/lib/db'
import { revalidatePath } from 'next/cache'

export async function createPost(formData: FormData) {
  const title = formData.get('title')
  await db.insert(postsTable).values({ title })
  revalidatePath('/blog')
}

Form Actions

The action attribute on a <form> binds directly to a Server Action. Forms work without JavaScript and hydrate into full reactive experiences when JS loads.

'use client'
import { createPost } from '@/app/actions'

export default function NewPostForm() {
  return (
    <form action={createPost}>
      <input name="title" placeholder="Post title" />
      <button type="submit">Publish</button>
    </form>
  )
}

useFormStatus

Access the pending state of a form's Server Action:

import { useFormStatus } from 'next/dist/client/form'

function SubmitButton() {
  const { pending } = useFormStatus()
  return <button disabled={pending}>{pending ? 'Saving…' : 'Submit'}</button>
}

Revalidation

After a mutation, invalidate cached pages so the next request fetches fresh data:

import { revalidatePath, revalidateTag } from 'next/cache'

revalidatePath('/blog')        // purge blog listing
revalidatePath('/blog/my-post')  // purge specific post
revalidateTag('posts')         // purge all fetches tagged 'posts'

Optimistic Updates

Update the UI instantly before the server confirms:

'use client'
import { useOptimistic } from 'react'
import { toggleLike } from '@/app/actions'

export function LikeButton({ initialLikes, postId }) {
  const [optimisticLikes, addOptimistic] = useOptimistic(
    initialLikes,
    (state, newCount) => state + newCount
  )

  async function handleLike() {
    addOptimistic(1)
    await toggleLike(postId)
  }

  return <button onClick={handleLike}>♥ {optimisticLikes}</button>
}

Server Action Security

  • Dead code elimination: Unused Server Actions are removed from the client bundle at build time
  • Secure action IDs: Next.js generates unguessable, non-deterministic IDs
// Used from Client Component → kept, gets secure ID
'use server'
export async function updateUserAction(formData: FormData) {}

// Never used → removed from bundle at build time
'use server'
export async function deleteUserAction(formData: FormData) {}

Route Handlers vs Server Actions

Server ActionsRoute Handlers
TriggerReact form submissionsExternal HTTP clients
ContextInside React componentsWebhooks, mobile apps, third-party calls
HTTP methodCalled as a functionGET, POST, etc.
