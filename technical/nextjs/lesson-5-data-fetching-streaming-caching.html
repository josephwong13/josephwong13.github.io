Lesson 5 — Data Fetching, Streaming & Caching

L5 Next.js Series · Lesson 5 of 5

App Router inverts the traditional data-fetching model: instead of fetching in Client Components with useEffect, you fetch in Server Components with async/await — simpler code, zero client bundle cost, and built-in caching.

fetch in Server Components

export default async function Dashboard() {
  const [user, stats] = await Promise.all([
    getUser(),
    getStats(),
  ])
  return <DashboardUI user={user} stats={stats} />
}

Fetch Memoization

Identical fetch calls within a render pass are automatically memoized — only one network request is made even if three components call it.

// Only ONE network request — Next.js deduplicates identical fetch() calls
const data = await fetch('https://api.example.com/user', { cache: 'no-store' })

Sequential vs Parallel Fetching

// Sequential — second request depends on first
const artist = await getArtist(artistId)       // blocks
return <PlaylistSection artistID={artist.id} />

// Parallel — independent requests
const [user, stats, notifications] = await Promise.all([
  getUser(), getStats(), getNotifications(),
])

Streaming with Suspense

Fast parts render immediately. Slow parts stream in as they resolve. Users see layout + skeleton instantly instead of a blank screen.

import { Suspense } from 'react'
import { BlogList, BlogListSkeleton } from '@/components'

export default async function BlogPage() {
  return (
    <div>
      <h1>Blog</h1>
      <Suspense fallback={<BlogListSkeleton />}>
        <BlogList />
      </Suspense>
    </div>
  )
}

For entire route segments, create a loading.tsx sibling to page.tsx — Next.js wraps it in Suspense automatically:

// app/blog/loading.tsx — shown while /blog loads
export default function Loading() {
  return <p>Loading posts…</p>
}
Pro tip: Design skeletons to match approximate dimensions of real content — prevents layout shift when data arrives.

Caching Directives

DirectiveEffect
export const dynamic = 'force-static'Cache at build time (ISR)
export const dynamic = 'force-dynamic'Render at request time — no caching
export const revalidate = 3600Revalidate route every 3600s
fetch(url, { cache: 'force-cache' })Cache this fetch (opt-in in Next.js 15)
fetch(url, { cache: 'no-store' })Never cache (default in Next.js 15)
fetch(url, { next: { tags: ['posts'] } })Tag for targeted revalidation

On-Demand Revalidation

Revalidate from a Server Action or Route Handler — useful for CMS webhooks:

import { revalidateTag } from 'next/cache'

export async function POST(req) {
  await processWebhook(await req.json())
  revalidateTag('posts')
  return NextResponse.json({ revalidated: true })
}
