Lesson 1 — App Router Fundamentals

L1 Next.js Series · Lesson 1 of 5

Next.js uses file-system routing — folders and files under app/ define your routes. This lesson covers the core building blocks: pages, layouts, dynamic segments, and navigation.

File-System Routing

Folders map to URL segments. Files map to UI.

// app/blog/page.tsx  →  /blog
export default function Page() {
  return <h1>Blog</h1>
}

// app/blog/[slug]/page.tsx  →  /blog/:slug  (dynamic)
export default function Page({ params }) {
  return <h1>{params.slug}</h1>
}
FileRoutePurpose
app/page.tsx/Home page
app/blog/page.tsx/blogBlog listing
app/blog/[slug]/page.tsx/blog/:slugBlog post
app/(auth)/login/page.tsx/loginRoute groups () don't affect URL

Root Layout (Required)

Every App Router project must have a root app/layout.tsx that exports a layout containing <html> and <body>. It wraps every page in the app.

// app/layout.tsx — must exist at project root
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}

Nested Layouts

Add layout.tsx inside a route folder to create nested layouts. The inner layout receives the outer layout's children via the children prop. Layouts persist across navigations — they do not re-render when the route changes.

// app/dashboard/layout.tsx
export default function DashboardLayout({ children }: { children: React.ReactNode }) {
  return (
    <div>
      <nav>Sidebar nav</nav>
      <main>{children}</main>
    </div>
  )
}

Dynamic Segments

Square brackets capture URL segments as params.

// app/blog/[slug]/page.tsx
export default async function BlogPost({
  params,
}: {
  params: Promise<{ slug: string }>   // ← async in Next.js 15
}) {
  const { slug } = await params
  const post = await getPost(slug)
  return <h1>{post.title}</h1>
}

Use generateStaticParams to pre-generate routes at build time:

export async function generateStaticParams() {
  const posts = await db.select().from(postsTable)
  return posts.map((post) => ({ slug: post.slug }))
}

Route Groups

Folders wrapped in (groupName) are route groups — they organize files without affecting the URL.

// app/(marketing)/about/page.tsx  →  /about
// app/(marketing)/pricing/page.tsx  →  /pricing
// app/(app)/dashboard/page.tsx      →  /dashboard

Linking & Navigation

Use <Link> for client-side navigation with automatic prefetching:

import Link from 'next/link'

export default function Nav() {
  return (
    <nav>
      <Link href="/blog">Blog</Link>
    </nav>
  )
}

For programmatic navigation, use useRouter from next/navigation (Pages Router uses next/router):

'use client'
import { useRouter } from 'next/navigation'

export function RedirectButton() {
  const router = useRouter()
  return <button onClick={() => router.push('/dashboard')}>Go</button>
}

searchParams Prop

Access URL query parameters via the searchParams prop. In Next.js 15 it is async:

export default async function Page({
  searchParams,
}: {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const { page, filter } = await searchParams
}
