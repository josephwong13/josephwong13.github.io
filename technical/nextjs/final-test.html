Answer Key

Q1: /pricing — route groups (parentheses) are purely organizational and do not affect the URL.

Q2: const { slug } = await params — in Next.js 15, params and searchParams are Promises.

Q3: 'use client' — the directive that crosses the server/client boundary.

Q4: revalidatePath('/blog') — purges the Next.js data cache so the next render fetches fresh data.

Q5: await cookies() — cookies() now returns a Promise in Next.js 15.

Q6: fetch is uncached by default in Next.js 15 — add { cache: 'force-cache' }.

Q7: <Suspense> with skeleton fallback — fast shell renders immediately, slow content streams in.

Q8: Dead code elimination — unused Server Actions are stripped from the client bundle at build time.

Q9: Development only — Turbopack for production is in beta in Next.js 15.

Q10: 'use client'

Q11: export const revalidate = 3600

Q12: cache revalidation (or ISR / Incremental Static Regeneration / on-demand revalidation)
